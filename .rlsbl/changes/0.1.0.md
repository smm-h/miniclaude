## 0.1.0

First release: lean, snappy inline terminal client for Claude Code.

<details>
<summary>Context</summary>

Initial public release of miniclaude, built on top of claudestream. Provides a
lean, snappy inline terminal client for Claude Code with dialog rendering, a REPL
loop, and tool-line output handling. Distributed on both PyPI and npm.

</details>

### Features

- Licensed under MIT.
- **Compact tool activity.** Tool calls and results appear as dense one-line entries (a marker glyph, the tool name, and a concise per-tool argument summary), with subagent activity indented and errors highlighted in red.
- **Rich streaming output.** Assistant prose and thinking now render live with markdown styling -- bold, italics, inline code, links, headers, bullet lists, fenced code blocks, and aligned tables -- streamed line-by-line as the response arrives.
- **Interactive REPL.** Run `miniclaude repl` for a live, scrollback-native session with Claude Code: assistant prose and thinking stream in as they arrive, tool activity shows as compact one-liners, and permission prompts and AskUserQuestion dialogs appear inline. Type ahead while a turn runs (extra lines queue and send in order), press Esc or Ctrl+C to interrupt, and use client-side slash commands (`/model`, `/mode`, `/context`, `/cost`, `/help`, `/quit`). Supports --profile, --model, --permission-mode, --cwd, --resume, and --continue-session.
- **Add your own answer to multi-select questions.** After picking option numbers on an AskUserQuestion multiSelect prompt, you can now type an extra free-text answer that is appended to your selections.

### Fixes

- **Failed tool calls now render as a red ✗.** Previously every tool result showed as a dim success ✓ regardless of outcome; errors are now visually distinct.
